## 🎯 Purpose

This repository provides a **practical evaluation** of multiple approaches to generate per-project specific development environments using Nix. The comparison is aimed at helping:

- 🔬 **Scientists** across many domains seeking reproducible research environments
- 💻 **Software developers** building maintainable and reproducible software artifacts
